<task type="auto">
  <name>Task 2: Create RLS policies and utility functions</name>
  <files>supabase/rls-policies.sql, supabase/functions.sql</files>
  <action>
    Create `supabase/rls-policies.sql`:
    - Enable RLS on ALL tables
    - profiles: Users can read all profiles, update only their own
    - clients: Authenticated users can CRUD all clients (shared resource)
    - products: Authenticated users can read all, create/update/delete their own or role='admin'
    - tasks: Authenticated users can read all, create any, update/delete own or assigned
    - task_checklists: Same access as parent task
    - invoices: Authenticated users can CRUD (created_by matches or role='admin')
    - invoice_items: Same access as parent invoice
    - quotations: Same as invoices
    - quotation_items: Same as parent quotation

    Create `supabase/functions.sql`:
    - Function `generate_invoice_number()`: Returns 'INV-YYYY-NNNN' format (e.g., INV-2026-0001), auto-incrementing per year
    - Function `generate_quotation_number()`: Returns 'QUO-YYYY-NNNN' format
    - Trigger on invoices INSERT to auto-set invoice_number if null
    - Trigger on quotations INSERT to auto-set quotation_number if null
    - Function `handle_new_user()`: Creates a profile row when a new auth.user is created (trigger on auth.users)
  </action>
  <verify>SQL is syntactically valid. RLS policies cover all CRUD operations on all tables. Functions use proper PostgreSQL syntax.</verify>
  <done>RLS policies for all 9 tables, auto-numbering functions for invoices/quotations, profile auto-creation trigger.</done>
